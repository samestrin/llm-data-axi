# Token benchmark: TOON (`--axi`) against JSON (`--json`)

Generated by `go run ./benchmarks -o benchmarks/RESULTS.md`. Each command runs once with `--json` and once with `--axi`, from inside the repository. Tokens are approximated as bytes/4; no tokenizer is involved. Saved is the share of JSON bytes that TOON does not spend. `tree`, `stats`, `grep` and `multigrep` print absolute paths in both formats, so their bytes, and the totals, shift with where the repository sits on disk; compare runs made from the same location.
